# 6. Pruebas y validación

Registra evidencias antes y después del hardening.

## Pruebas mínimas
- Conectividad entre el servidor auditor y cada dispositivo.
- Acceso SSH administrativo autorizado.
- Ejecución de auditoría en modo de solo lectura.
- Existencia del respaldo previo a cambios.
- Aplicación de los controles seleccionados.
- Nueva auditoría y comparación de resultados.
- Verificación de que interfaces, VLAN, rutas y políticas necesarias continúan operativas.

## Resultados
| Prueba | Resultado | Evidencia |
|---|---|---|
| Auditoría inicial | Pendiente de completar | Informe inicial |
| Respaldo | Pendiente de completar | Archivo de backup |
| Aplicación de reglas | Pendiente de completar | Log de ejecución |
| Auditoría posterior | Pendiente de completar | Informe final |
| Conectividad y servicios | Pendiente de completar | Capturas/comandos |

Sustituye “Pendiente de completar” por resultados observados; no inventes resultados.
