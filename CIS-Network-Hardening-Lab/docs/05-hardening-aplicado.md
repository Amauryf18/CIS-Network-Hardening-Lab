# 5. Hardening aplicado

Por cada cambio realizado, registra:

| Campo | Descripción |
|---|---|
| Dispositivo | Equipo donde se aplicó el cambio |
| Control | ID y recomendación |
| Estado inicial | Resultado de auditoría inicial |
| Cambio | Comando o configuración aplicada |
| Respaldo | Archivo de respaldo previo |
| Estado final | Resultado de auditoría posterior |
| Evidencia | Captura o extracto de informe |

No incluyas secretos ni contraseñas en esta documentación. Adjunta capturas reales en `docs/images/`.
